## 💻 Running Locally

To preview or run this website locally on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/i-kabir/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**
   - Double-click `index.html`, or
   - Using Python:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000](http://localhost:8000) in your web browser.
